# Predate Spine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A leak-tested path from dated SEC filings to a Qlib ablation result (price features alone against price plus news factors), then a schema-constrained language-model parser behind the same interface.

**Architecture:** An ICM workspace with one Python package, `predate`. Deterministic modules are ported from the tested design listings. The first event source is rule-typed 8-K filings, so the first milestone needs no language model. The parser is added afterwards behind the `EventExtractor` interface and writes into the same event store under its own `parser_version`.

**Tech Stack:** Python 3.11, uv, pyqlib 0.9.7, lightgbm 4.7, pandas 3.1, numpy 2.4, pydantic 2.14, pyarrow, pytest 9. The parser track adds a local llama.cpp server.

**Spec:** `docs/superpowers/specs/2026-11-06-predate-design.md`. Tested reference code: `docs/superpowers/specs/2026-11-06-predate-design-listings/`.

**Tracks that depend on this plan:** `2026-11-06-precedent.md` and `2026-11-06-ripple.md` both start after Task 11. Tasks 13 to 16 (the parser) run alongside them.

## Global Constraints

- Python 3.11. One package manager, uv, with `uv.lock` committed. Tests run with `uv run pytest -q`.
- Only modules named `parser_*`, `event_parser` and `openai_compat_extractor` may call a language model. Everything else is deterministic.
- `first_seen_utc` is required on every record. Naive timestamps are rejected. Time is tz-aware UTC internally.
- Every factor builder ships with a truncation-invariance test (spec 4.5).
- `qlib.init` always passes `region="us"` and an SQLite experiment manager.
- In `NestedDataLoader`, the price loader is first and `join="left"`.
- Label under convention C1: `Ref($open, -2)/Ref($open, -1) - 1`; `deal_price` is `open`; `label_horizon` is 2.
- No article text, price data or model weights are committed. `stages/*/output/`, `data/` and `vendor/` are git-ignored.
- Zero spend. No paid API, paid data or rented compute without the owner's yes. Model and dataset downloads are named (source, size) and approved first.
- The SEC User-Agent comes from the environment variable `PREDATE_SEC_USER_AGENT`. No contact detail is written into the repository.
- Stage explicit files in every commit. Pushing a feature branch to the private `origin` is allowed (owner instruction, 2026-11-06). Merging to `main` needs the owner's yes.
- Every result is recorded in `docs/STATUS.md` with one evidence label: `SYNTHETIC`, `LIVE-DATA`, `LIVE-MODEL` or `NO LIVE RUN`.
- If Qlib or a data source behaves differently from the spec, stop the task and report. Do not invent a substitute.

## Review Focus

1. An 8-K that reports several items: one event per item, identical timestamps. (Test in Task 5.)
2. An event for an instrument with no price row on its effective session (halt, not yet listed): the left join drops it, so it must be counted in the run manifest as `events_without_price_row`, never lost silently. (Test in Task 9.)
3. An event later than the provider's last session: `effective_session` is missing, and the record is excluded and counted as `unaligned_records`. (Test in Task 4.)
4. A company whose ticker changed: events are keyed by CIK; a CIK with no symbol in the provider is `unresolved` and counted. (Test in Task 6.)
5. A day with no events anywhere: the factor panel is empty and the dataset returns zeros, not an error. (Test in Task 9.)

## Task Cycle

Every task uses the same five steps. The task lists only what is specific to it.

- **Step 1:** write the listed tests.
- **Step 2:** run them; they must fail for the stated reason (usually `ModuleNotFoundError` or `ImportError`).
- **Step 3:** implement the listed signatures.
- **Step 4:** run the task's tests, then the whole suite: `uv run pytest -q`. All green.
- **Step 5:** commit the listed files with the given message, and add a line to `docs/STATUS.md`.
